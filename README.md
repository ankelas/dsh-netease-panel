# dsh-netease-panel

网易云音乐控制面板，作为 DSH（DeepSeek Harness）Web UI 插件运行。它不内嵌网页播放器，而是驱动你本机已登录的网易云音乐客户端：显示当前播放、控制播放/切歌/音量，浏览歌单并点播歌曲，同时在页面里显示逐字同步歌词。

> 仅支持 Windows。需要本机安装并运行网易云音乐客户端（桌面版或 Microsoft Store 版），且已至少启动过一次。

## 功能

- **当前播放**：歌名、歌手、播放/暂停状态，跟随客户端实时更新；
- **播放控制**：上一首 / 播放暂停 / 下一首（系统媒体会话）；
- **歌单与点歌**：列出账号的公开歌单，点进去看歌曲列表，点任意一首即在客户端播放；支持「播放全部」；
- **播放模式**：顺序 / 随机 / 单曲（由面板队列驱动，一首结束后推进下一首）；
- **音量**：0–100 滑杆，控制网易云那一路的音频会话音量；
- **同步歌词**：读取客户端本地播放日志获得实时进度，从网易云取原文与翻译，在页面里逐字显示、随机位置、唱完淡出；
- **外部歌词窗口**：面板里的「外部歌词」开关可以把歌词放到 DSH 之外的独立置顶小窗（基于 Document Picture-in-Picture），切换应用时也能看到；
- **打开客户端**：一键启动或切回网易云。

面板挂在 `shell.overlay`，切换会话、切换面板时音乐不中断。

## 环境要求

- Windows 10/11；
- DSH `>= 0.2.1-rc.2`（Web 或桌面客户端）；
- 网易云音乐客户端已安装、已登录，并且至少运行过一次（用于生成 `cloudmusic.elog`）；
- 客户端安装在常见位置，或已注册 `orpheus://` 协议（插件会从注册表与常见安装目录自动查找）。

## 安装

从 GitHub 仓库直接安装：

```bash
dsh plugin --profile <你的 profile> add github:ankelas/dsh-netease-panel
```

或下载 Release 里的 `dsh-netease-panel-1.0.0.tgz`，用本地路径安装：

```bash
dsh plugin --profile <你的 profile> add <tgz 绝对路径>
```

安装后刷新页面，右下角出现官方网易云图标，点开即用。

## 使用

1. 打开面板，确认「当前播放」有内容（没有就先打开网易云客户端放一首）；
2. 点「我的歌单」里的任意歌单 → 歌曲列表；
3. 点单曲播放，或用「顺序 / 随机 / 单曲」控制后续曲目；
4. 「歌词」开关打开后，歌词会以随机位置、逐字出现的方式显示在页面上，唱完约 8 秒后淡出；
5. 音量滑杆控制客户端输出音量。

## 实现说明

- 播放状态与进度来自客户端本地日志 `%LOCALAPPDATA%\NetEase\CloudMusic\cloudmusic.elog`；
- 播放控制与当前曲目通过 Windows 媒体会话（SMTC）完成；
- 音量通过 Windows 按应用音频会话（`ISimpleAudioVolume`）设置；
- 歌单、歌曲与歌词使用网易云公开接口；
- 点播歌曲通过客户端 `orpheus://` 协议发送。

## 已知限制

- 歌单列表只包含账号的**公开歌单**；私密歌单不会出现；
- 歌词依赖客户端日志，客户端版本差异较大时可能读不到；
- 音量是「按应用会话音量」，客户端在外部修改后会短暂回弹，插件会重复应用以保持目标值；
- 播放模式由面板队列驱动，与客户端自身的播放模式可能同时生效；
- 仅支持 Windows。

## 开发

插件是一个纯手写 bundle，无需构建：

- `index.js`：Host 半侧（日志解析、HTTP 路由、歌单/歌词抓取）；
- `client.js`：浏览器半侧（`shell.overlay` 中的面板与歌词层）；
- `helper.ps1`：常驻 PowerShell，负责 SMTC 与音频会话；
- `cordis.patch.yml`：bundle 装配清单。

本地安装：

```bash
dsh plugin --profile <profile> add link:<本目录绝对路径>
```
